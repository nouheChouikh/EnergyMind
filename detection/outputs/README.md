# Outputs

Everything in this folder is generated by the scripts in `detection/evaluation/`. Never edit these files by hand: change the code or the settings, then rerun the script.

| Folder | Written by | What it holds | Committed? |
|---|---|---|---|
| `saved_model/` | `run_learning.py`; `run_practice.py` adds the confidence table | learned from 2018: the losses numbers of each phase, the forest, T, the learning year's scores. Stored with them, not learned: the street wiring the model was trained on, the confidence table (from practice), and the settings and library versions used | yes: the operator app loads the model from here |
| `practice_results/` | `run_practice.py` | the practice report: the measures for the forest and for the threshold baseline, and the incidents found | yes |
| `final_test_results/` | `run_final_test.py` | the final report: the same measures on the final-test months, the held-out problems, and the confidence check | yes, written once: `run_final_test.py` refuses to run if this folder already exists |

Each folder appears the first time its script runs.
